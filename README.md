# ASD — Data Structures and Algorithms

Solutions to programming exercises from the *Data Structures and Algorithms* course (2nd year, Computer Science, UMCS Lublin), implemented in C++.

## Repository Structure

```
ASD/

├── Algorytmy II/       # Algorithms II — 15 exercises
└── Egzamin ASD I/      # ASD I exam solutions (Feb 2020)
```
